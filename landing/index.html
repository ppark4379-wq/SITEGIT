THE DISCONNECTED SITE

계획은 문서에, 실행은 장비에,
검증은 사람의 기억에 남아 있습니다.

SiteGit은 흩어진 세 흐름을 하나의 운영 맥락으로 연결합니다.

01

계획의 단절

도면과 공정표가 장비가 이해하는 작업 단위로 이어지지 않습니다.

02

실행의 불확실성

어떤 조건으로 무엇을 수행했는지 공통된 기준이 부족합니다.

03

검증의 공백

결과 데이터와 관리자 판단이 한 이력으로 남지 않습니다.

SiteGitPlan → Execute → Evidence → Release

계획부터 승인까지, 자율화 작업의 신뢰 가능한 연결 구조

01 · PLAN COMPILER

현장 계획을
작업 단위로 컴파일

구역, 목표 물량, 허용오차, 장비 역할을 하나의 Work Package로 묶어 실행 조건을 명확히 전달합니다.

  • 구역별 작업 목표와 제약조건
  • 주 작업·상차·운반 장비 배정
  • Plan Version 기반 변경 추적

02 · EQUIPMENT REGISTRY

제원과 Capability로
장비를 정확히 연결

제조사 공개 제원과 프로젝트 요구조건을 분리해 관리하고, 작업에 맞는 장비 조합을 빠르게 확인합니다.

  • 실제 장비 제원 기반 Registry
  • 작업 유형별 Capability Matrix
  • 장비팀 역할·수량 연결

03 · LIVE EXECUTION

현장의 실행 상태를
하나의 화면에서

구역별 진행률, 장비 상태, 잔여 물량과 위험 신호를 지도 중심 대시보드에서 동시에 파악합니다.

  • 공간 기반 Zone 모니터링
  • Raw / Qualified 진척도 구분
  • 관리자 Command와 상태 신호

04 · EVIDENCE GATE

장비의 결과를
믿을 근거로 전환

계획 대비 결과, 관측 범위, 신뢰도와 추가 확인 기록을 하나의 Evidence Bundle로 구성합니다.

  • Plan / Before / After 비교
  • Evidence 완전성과 관측 신뢰도
  • 자동 Release Gate 계산

05 · MANAGER ACTION

충돌은 숨기지 않고
결정 가능한 객체로

물리적 미달과 Evidence 부족을 구분해 추가 확인, 보완 작업, 보류 또는 승인으로 연결합니다.

  • Conflict 유형과 영향 분리
  • 사람이 개입하는 최종 Gate
  • 보완 Work Package 즉시 발행

06 · VERSION & AUDIT

모든 변화와 판단을
연결된 이력으로

계획, 실행, Evidence, 보완, 관리자 결정을 시간 순서의 Version과 Audit Trail로 남깁니다.

  • Plan·Work·Evidence 연결 이력
  • 결정 주체와 시점 기록
  • 현재 상태 Snapshot과 내보내기

HOW SITEGIT WORKS

계획이 실행되고,
실행이 신뢰가 되는 과정

  1. 01

    Site Data

    현장 좌표와 기준 데이터를 준비합니다.

  2. 02

    Work Package

    계획을 실행 가능한 조건으로 묶습니다.

  3. 03

    Autonomous Work

    장비팀이 작업을 수행하고 상태를 반환합니다.

  4. 04

    Evidence & Release

    결과를 검증하고 관리자가 승인합니다.

SITEGIT PROTOTYPE

자율화 장비가 일하는 현장에는
새로운 운영 인터페이스가 필요합니다.

SiteGit은 건설사의 계획과 장비의 실행 사이에 신뢰 가능한 연결 구조를 제안합니다.
